## Description

This code snippet demonstrates the implementation of a "Sector Similarity Explorer" web application using Python and React. The Python part processes a list of points to compute sector embeddings and their pairwise cosine similarities, ultimately generating a correlation matrix. The React component (`SectorSimilarity`) creates a user interface for exploring these similarities visually, allowing users to select sectors, compare cosines, and visualize data with heatmaps, tables, and bar graphs. The UI also provides interactivity through search filters and toggle options for data display modes. Finally, a widget is created and added to the UI framework for visualizing sector similarities in an interactive manner.
